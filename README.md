We created a central hub, our portfolio site, to showcase just a few of our DevOps projects which links to each projects Github repository. 
This projects displays our experience and skills and gives a brief description of our projects. 
Contact info displays our email, LinkedIn, the main page for our GitHub repository, and our Medium article site. 


**Tools Used:**

AWS Amplify - an AWS hosted service that allows us to host our Portfolio app 
Route 53 - we used Route 53 in order to create our custom domain which we then pointed to our Amplify Portfolio app
